# gh-notify

GitHub の通知をターミナルでトリアージする gh 拡張。

> "通知確認"は作業ではなく、次の作業対象をトリアージし、コンテキストの切り替え作業。
> ``トリアージ = 作業間のコンテキストを切り替える場所(次の作業をトリアージするもの)``

gh notify は次の作業に移るための通知のトリアージ工程を助けます。

## なにをするか

- 通知の一覧表示（カレントリポジトリ / 全リポジトリ）
- 既読化 / 未読化
- ブラウザで開く

## やらないこと

- コメント投稿、レビュー、チェックアウト
- 通知以外（PR 一覧、Issue 一覧、CI 状況）

より高機能な通知ダッシュボードが必要な場合は gh-dash を検討してください。
gh-notify は機能の多さではなく、削ぎ落とすことで通知トリアージを速くすることを目的としています。

## Quick start

```sh
gh extention install umekikazuya/gh-notify
```

## How to

```sh
gh notify
```
